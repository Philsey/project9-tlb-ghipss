# AI-Use Declaration — Project 9: Translating Trust

This project utilized AI-assisted tools in the following capacities:

## Tools Used
- **ChatGPT / Large Language Models:** Assistance with code structure and diagram descriptions
- **AI Image Generation:** Generation of architecture diagrams and presentation visuals based on detailed textual prompts.

## Nature of Use
- **Code:** AI provided starter templates and structural guidance for `demo_tlb_sim.c`, `starter_tlb_sim.c`, and `gen_ghipss_trace.py`. All code was reviewed, modified, and validated by the team.
- **Documentation:** AI assisted in drafting the project charter, requirements specification, and presentation slide outlines. Final content was reviewed and edited by team members.
- **Diagrams:** AI generated visual diagrams from detailed technical specifications provided by the team.

## Verification
All AI-generated content was verified against the project specification, peer-reviewed papers (Basu et al., Hennessy & Patterson), and course requirements before inclusion in deliverables.
